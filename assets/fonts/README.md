# Bundled Latin default

`TinyPDFSans.ttf` and `TinyPDFSans-Italic.ttf` are Latin/Vietnamese/punctuation subsets of Noto Sans, with `wght` and `wdth` axes retained. Each PDF embeds a further static subset at its actual coordinates. The files contain 1,124 and 1,123 Unicode mappings respectively; they do not replace the optional script packs.

Source: Google Fonts commit `cc39c4c2c304bc368c9b7c311ea2bcc6013299fe`, `ofl/notosans/NotoSans[wdth,wght].ttf` and `NotoSans-Italic[wdth,wght].ttf`. Full source URLs, SHA-256 checksums and license checksum are pinned in `tests/fonts/manifest.json`. The included `OFL.txt` must accompany redistribution. Subsetting used FontTools 4.61.1.
